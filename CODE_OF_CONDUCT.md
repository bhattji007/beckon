# Code of Conduct

Be kind, be direct, assume good faith. Harassment, personal attacks and discrimination are not tolerated anywhere in this project (issues, PRs, discussions, chat).

Maintainers will remove, edit or reject comments, commits, issues and PRs that break this, and may ban repeat offenders.

Report problems privately to the maintainer via the email on the GitHub profile of @bhattji007. Reports are handled confidentially.

This is a condensed form of the Contributor Covenant 2.1 (https://www.contributor-covenant.org/version/2/1/code_of_conduct/), which applies in full.
